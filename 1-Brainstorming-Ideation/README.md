# 1. Brainstorming & Ideation Phase

## Project Title: Import Data using Transform Maps (Spreadsheet)

### Problem Statement:
Organizations have bulk data in Excel sheets. Manually entering it into ServiceNow is time-consuming and error-prone.

### Proposed Solution:
Use ServiceNow Import Sets and Transform Maps to automatically import spreadsheet data into the target table.

### Objectives:
- Automate bulk data import
- Reduce manual effort and errors
- Ensure data accuracy using Coalesce
